# 项目交接

## 当前目标

- 发布 `1.2.0`：默认适配 OpenCode Go 套餐（仅提供 DeepSeek V4.1 Flash），保留 DeepSeek 浏览器 SDK 与自定义接口。

## 已完成

+ 新增 `js/providers.js` 服务商注册表：统一描述 Endpoint、模型、鉴权头、模型列表地址与 usage 解析。
+ 默认配置切换为 OpenCode Go：`aiChannel=api`、`apiProvider=opencode-go`、模型 `deepseek-v4.1-flash`。
+ OpenCode 协议适配：请求携带 `x-opencode-session` 稳定会话 ID；流式请求开启 `stream_options.include_usage`。
+ 用量展示：解析 `usage.opencode`（`billing_source` / `allowance` / `tokens`），设置页显示本次计入的 Go 套餐额度。
+ 设置页新增「服务商」下拉、固定项只读样式、OpenCode Console 取 Key 链接、测试连接按钮。
+ API Key 按服务商分别保存（`settings.apiKeys`），切换服务商不会把旧 Key 发给新服务商。
+ 旧配置迁移：缺少 provider 字段时按 Endpoint 反推；无法识别则保持「自定义接口」并保留原 Endpoint / 模型 / Key。
+ 错误提示本地化：OpenCode Go 的 401 / 403 / 429 附带排障建议；模型列表兼容 `/inference/go/v1/models`。
+ `manifest.json` 增加 `https://opencode.ai/*` host 权限并提升版本至 `1.2.0`，同步更新 README、落地页与 CHANGELOG。
+ 新增 `tests/opencode-go-provider.test.cjs` 与 `tests/opencode-go-background.test.cjs`，连同原有测试全部通过。

## Next Steps

1. 重新加载扩展，在设置页确认默认显示「OpenCode Go」、Endpoint 只读、模型为 DeepSeek V4.1 Flash。
2. 填写真实的 OpenCode Go API Key，完成一次「总结 → 追问」，确认流式输出与额度展示正常。
3. 在 Console 将 Privacy → Regions 设为 Global 后验证 DeepSeek 模型的可用性（部分网络环境需要）。
