+ 完成 JavaScript 语法检查与 `git diff --check`。
+ 将运行时状态、设置默认值、界面默认选中项及所有缺省回退统一调整为快速模式。
+ 新增默认模式测试，确认无保存配置时加载 `fast`，发送层未指定模式时也实际发送 `fast`。

+ 在 `CHANGELOG.md` 新增 `1.1.5` 记录，包含追问会话修复和默认快速模式变更。
